# Public Disclosure Policy

This repository is a public portfolio surface for VLADS Future. It is designed to communicate product direction and engineering scope without publishing proprietary implementation details.

## Appropriate for this repository

- Product positioning and intended use cases.
- High-level engineering themes.
- Conceptual artwork clearly presented as conceptual.
- Conservative descriptions of privately validated work.
- Links to intentionally public engineering showcases.

## Kept private

- Commercial source code or proprietary algorithms.
- Internal architecture diagrams, protocol details, security mechanisms, or trust boundaries.
- Credentials, tokens, private endpoints, hostnames, IP addresses, deployment paths, or local filesystem paths.
- Private test evidence, raw logs, internal metrics, unreleased binaries, or configuration.
- Claims that depend on unpublished performance data or independent certification.

## Claim standard

Public copy must distinguish among:

1. **Product direction** - what an initiative is intended to help with.
2. **Private validation** - areas exercised in controlled internal engineering work.
3. **Publicly demonstrated capability** - only what is intentionally exposed in a public artifact.

Private validation must not be presented as general availability, independent certification, guaranteed reliability, guaranteed accuracy, or guaranteed business or financial outcome.

## Publication gate

Before publication, repository QA should confirm that local links resolve and that public Markdown does not contain obvious private infrastructure paths or identifiers. Editorial review remains responsible for factual accuracy and appropriate scope.
